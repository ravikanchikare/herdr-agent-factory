Create or Create & Run from a Git repository into a managed Agent Draft
worktree. Edit and run Drafts from one unified page, publish immutable semantic
Versions as commits and annotated tags, and create concurrent Drafts from any
Version. The sidebar and search expose active Drafts rather than Overview and
Version destinations.
